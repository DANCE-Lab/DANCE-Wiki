# Protocol

## Prepping

Make sure both testing rooms have ample art materials (from the MIDB, not DANCE) and cameras are set up.

Once participants arrive, greet them warmly and get them ready for optimazation. Let them pick their backpack if they have strong opinions.

Optimize them one at a time using aurora.
